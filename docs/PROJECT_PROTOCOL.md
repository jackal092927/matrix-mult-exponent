# A reviewable distributed research relay

The project is a coordinated set of independent mathematical work streams with
public artifacts. It is not a claim that more PRs or more agents imply a better
bound. The launch establishes a problem, exact finite baselines, three research
cards and an independent checking lane.

## Before a run

Read the pinned sources and scoped failures. Freeze a card giving the field,
tensor family, equations, target, baseline, resource limit, controls and stop
conditions. Name the exact implication the proposed construction would prove.
Use one canonical continuation file; avoid reopening excluded targets merely
because a different session has not seen the earlier evidence.

## Evidence return

A worker returns a proof/certificate or a named obstruction, source pins,
replay instructions and a claim-scope table. All computations report completed
denominators and deliberate corrupt controls where applicable. Keep numerical
leads separate from recovered exact coefficients. Timeouts and failed candidates
remain part of the record.

The independent reviewer reconstructs identities and theorem hypotheses without
executing the search producer. It records accepted finite facts, unresolved
lemmas, counterexamples and cost-model gaps. A locally consistent identity, an
independent replay and a theorem about omega are different acceptance states.

## Public integration

Research directions live in GitHub issues; complete contributions arrive as PRs.
The coordinator integrates reviewed evidence and records predecessor revisions.
The initial read-only finite gate accepts rational bilinear identities; it cannot
validate a symbolic border-rank family, universal spectral inequality or algebra
smoothing. New certificate kinds need a specified contract and separate audit.

Publishing a numerical improvement requires the complete asymptotic transfer and
an independent adversarial proof audit. Mathematical novelty requires comparison
with current primary work. This protocol itself establishes neither.

## Continuation and resources

Each session saves its decision and next bounded card before returning. Distinct
lanes may continue in parallel; one experiment has one owner. Existing long-term
monitoring of the observatory remains separate from these new first checkpoints.
No additional background schedule is created just by opening a research session.
