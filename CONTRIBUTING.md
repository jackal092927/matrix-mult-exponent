# Contributing to Omega Relay

We welcome a proposed construction, precise conjecture, exact certificate,
independent audit, reusable search improvement or documented method boundary.
Start with an issue that names the field/model and exact target. Do not claim
an improving omega merely from a local rank record or numerical residual.

Every research PR should include the mathematical object and basis convention,
exact statement and quantifiers, pinned predecessor/source revisions, changed
construction, field and rank notion, all asymptotic costs, complete proof or
certificate, reproduction commands and an independent evaluation receipt.
Identify unresolved premises, inaccessible history and unperformed checks.

For finite rational certificates follow docs/CERTIFICATE_CONTRACT.md. The checker
does not execute producer programs. For numerical discoveries recover exact
coefficients and reject corrupted candidates before promotion. Degenerations
must verify every coefficient and limiting term; smoothability needs a real flat
family, not a dimension count or a statement about a parent algebra.

Keep research states distinct: LEAD, CANDIDATE, EXACT_FINITE_CHECK,
INDEPENDENT_REPLAY, CONDITIONAL_THEOREM, THEOREM_SCOPE_REVIEW, and INTEGRATED.
REFUTED, METHOD_BOUNDARY and UNKNOWN are useful durable outcomes. A merged PR
does not certify a global exponent or mathematical priority.

Use bounded experiments with complete source/seed/configuration hashes, actual
resource receipts, success/failure denominators and explicit stop rules. Keep
large scratch data and private operations outside ordinary Git. Never upload
credentials, private correspondence or session transcripts.

Existing work should be credited as inherited construction, new component,
integration and independent verification. State the license for new files and
retain notices for reused material. Isomorphic/renamed/format-only variants are
not separate scientific advances. Public claims and scoreboard changes need
independent review of scope and current prior work.
